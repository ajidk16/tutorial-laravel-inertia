# Instalasi Dependencies Inertia.js (Client Side)

Untuk memulai penggunaan Inertia.js pada sisi client, Anda perlu menginstal beberapa dependencies utama. Berikut langkah-langkahnya:

## 1. Install Inertia.js dan Adapter

Jalankan perintah berikut sesuai dengan framework frontend yang Anda gunakan:

### React
```bash
npm install @inertiajs/inertia @inertiajs/inertia-react
```

### Vue 3
```bash
npm install @inertiajs/inertia @inertiajs/inertia-vue3
```

### Svelte
```bash
npm install @inertiajs/inertia @inertiajs/inertia-svelte
```

## 2. Install Progress Indicator (Opsional)

Untuk menampilkan progress bar saat melakukan navigasi, Anda bisa menambahkan NProgress:

```bash
npm install nprogress
```

## 3. Konfigurasi

Setelah dependencies terinstal, Anda dapat mulai mengkonfigurasi Inertia.js sesuai dokumentasi resmi untuk framework yang digunakan.

> Referensi: [Inertia.js Client-side Setup](https://inertiajs.com/client-side-setup#install-dependencies)
